The keyboard can only remember its own built-in effects, so these are played by the small Dark Mount Studio tray app. This page just changes its settings — close the tab whenever you like. While the tray app is not running (or “Effects on” is off), the keyboard shows its built-in lighting. If Windows “Dynamic Lighting” is switched on for the keyboard, switch it off — it competes for the same lights.
